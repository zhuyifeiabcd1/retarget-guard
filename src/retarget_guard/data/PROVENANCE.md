# Demonstration asset provenance

`demo_source.npz` and `demo_target.npz` contain only body geometry, triangle
indices, skin weights, and the game-engine skeleton from characters generated
with MPFB. They contain no SMPL-family data and no recorded motion.

The source is a slim generated body (gender 1, muscle 0.4, weight 0.15, height
0.5). The target is a heavy generated body (gender 1, muscle 0.2, weight 1.0,
height 0.45). Both used age 0.5, proportions 0.5 and the default game-engine
rig. Helper geometry was removed. Clothing, shoes, textures and
other mesh layers are excluded. Blender coordinates were rotated to
right-handed Y-up metres with `(x,y,z) -> (x,z,-y)`.

The MakeHuman Team's [MPFB license](https://github.com/makehumancommunity/mpfb2/blob/master/LICENSE.md)
separates GPLv3 program code from CC0 assets. Section C covers the base mesh,
shape targets, rigs and related data. Section D explicitly covers generated
graphical data and exported model files. The local MPFB license was checked
against the official repository on 2026-11-06. The CC0 dedication is reproduced
in `CC0-1.0.txt`.

No MPFB program logic is included. The procedural motion is generated by
`retarget_guard.demo.procedural_motion` using NumPy and numerical IK, with no
motion dataset or model inference.
